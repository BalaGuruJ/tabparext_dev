# tabpagext-investigation Skill

## Purpose
Provides read-only investigation protocols for analyzing the `tabPagExt` repository, runtime files, and development governance without making modifications.

## Instructions
1. **Inspect Before Assuming:** Always examine existing files (`src/`, `extension/`, `dev/`) before drawing conclusions or proposing changes.
2. **Identify Relevant Files:** Locate the precise files relevant to the investigation scope (e.g., manifest files, static assets).
3. **Review Governance:** Check development governance and documentation under `dev/governance/` and `dev/README.md` to align with project standards.
4. **Distinguish Facts from Assumptions:** Clearly separate empirically verified observations from hypotheses or suppositions.
5. **Report Findings:** Provide a structured, objective summary of observations, evidence, and potential paths forward.
6. **Strict Read-Only Constraints:** 
   - Do NOT modify any runtime files (`src/`, `extension/`).
   - Do NOT modify governance files during investigation.
   - Do NOT manufacture defects or assume failures without evidence.
7. **Recommendation Threshold:** Only recommend a structured implementation task when empirical evidence fully supports the need for change.
