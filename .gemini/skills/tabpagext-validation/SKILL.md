# tabpagext-validation Skill

## Purpose
Provides pure validation protocols to determine whether the current `tabPagExt` runtime implementation and project scaffold pass or fail structural and functional checks.

## Instructions
1. **Validate Current State:** Inspect the current project state against established project architecture and scaffold requirements.
2. **Execute Approved Checks:** Run only appropriate, non-destructive tests, validation scripts, or structural inspections.
3. **Report Explicitly:** Deliver a clear **PASS** or **FAIL** report detailing every checked component.
4. **Identify Failures:** Accurately pinpoint failing files, broken constraints, or missing requirements to preserve debugging context.
5. **Strict Non-Modification Constraints:**
   - Do NOT modify any runtime implementation files (`src/`, `extension/`).
   - Do NOT attempt to automatically "fix" identified failures.
   - Do NOT silently alter configuration files or `.env`.
   - Do NOT install unapproved dependencies or packages.
   - Do NOT perform Git commits or pushes.
