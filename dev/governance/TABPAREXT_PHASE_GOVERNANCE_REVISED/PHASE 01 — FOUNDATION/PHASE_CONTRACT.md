# TABPAREXT — PHASE 01 CONTRACT
## Foundation & Evidence

### Objective
Establish the governed development foundation, deterministic evidence laboratory, and source-knowledge bridge for TABPAREXT.

### Scope
- Define the five-phase project lifecycle and phase-gate discipline.
- Establish Task → Response/Evidence → Review → Closure artifacts.
- Establish the TWB fixture as the initial deterministic development/testing source.
- Define the boundary between TWB metadata and future live Tableau Extension API data.
- Preserve the lightweight vanilla-JS / no-build-tool runtime philosophy.
- Establish the Tableau source-knowledge bridge between deterministic TWB
  evidence and future Tableau Extension API verification.

### In Scope
- Governance structure and phase rules.
- Existing Gemini CLI command/skill usage.
- TWB fixture strategy.
- Metadata/parser evidence strategy.
- Initial project architecture boundaries.

### Out of Scope
- Tableau Extensions API implementation.
- Runtime worksheet extraction.
- LOD engine implementation.
- Report designer implementation.
- Pagination implementation.
- PDF generation.
- Production deployment.
- Resolving Tableau Extension API capability questions.

### Entry Criteria
- Repository structure has been inspected.
- Product direction has been discussed.
- Five major phases have been agreed conceptually.
- Existing Gemini governance is available.

### Exit Criteria
- Governance contract is documented.
- Phase workflow is documented.
- TWB fixture strategy is documented.
- Runtime-vs-fixture boundary is explicit.
- Review identifies no unresolved foundation blocker.
- Tableau source-knowledge bridge identifies Known, Unknown, and To Verify
  capabilities between the TWB fixture and future Extension API runtime.

### Gate
Phase 01 may close only after independent review confirms the above evidence.
