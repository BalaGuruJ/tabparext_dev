# TABPAREXT Phase Governance

This package contains the revised TABPAREXT five-phase governance hierarchy.

Phase 01 contains actual foundation/contract/task/review/closure content.
Phases 02–05 contain structural placeholders only and should be opened
and populated when their preceding phase is accepted.

Upload destination inside the repository:

    governance/phases/

Do not overwrite existing `.gemini/` governance commands or skills.
